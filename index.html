⚠ Browser Security Block
Your browser is blocking the AI connection because the file is running locally.
Fix — Choose one of these options:

Option 1 (Easiest): Open the file in Microsoft Edge instead of Chrome — Edge allows local file API calls.

Option 2: In Chrome, launch with reduced security:
chrome.exe --disable-web-security --user-data-dir="C:/Temp/chrome_dev"

Option 3: Use a simple local server — open Command Prompt in the file's folder and run:
python -m http.server 8080
Then open: http://localhost:8080/mkhondo-asset-agent.html
